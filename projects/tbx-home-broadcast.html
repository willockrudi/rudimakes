TBX Home Broadcast Station 🛠 In Progress

A home television broadcast station on a Raspberry Pi 5, built out of a media collecting habit. Numbered channels, a real schedule, and a seek algorithm that drops you into whatever is playing right now rather than starting a file from the beginning. FastAPI and mpv over a Unix socket, a React UI driven by an IR remote, and a front panel run by an ATtiny85.

Technical Notes

What It Is

A broadcast station, not a media server. The distinction is the schedule. A media server hands you a library and waits for you to pick something; TBX decides what is on and you tune to it.
It came out of collecting media as a hobby. Past a certain size a collection stops being something you browse - there is too much of it to pick from, and scrolling a grid of everything you own is a worse experience than having something already playing. TBX is what to do with a collection once it has got to that point.
It runs on a Raspberry Pi 5 with 16GB of RAM and boots straight to playback. A FastAPI backend drives an mpv playback engine over a Unix socket. The web UI is React, and the whole thing is operated with a handheld IR remote. Holding T drops out of playback into a kiosk mode for managing the media directly, so adding and organizing the collection does not mean going to a terminal.
Built solo over about two years.

The Seek Problem

The hard part of making something behave like a broadcast network is that there is no play button. If you tune to Channel 4 at 8:00 on a Tuesday, the right thing to do is join whatever is airing, partway through, exactly where it would be.
So a channel is not a playlist with a cursor. It is a schedule plus a clock. On every tune the backend resolves the current wall time against the channel's schedule, works out which item is airing and how far into it the moment falls, and seeks mpv to that offset. Nothing is stored about where a viewer left off, because a real channel does not care - it runs whether anyone is watching or not.
Two viewers tuning to the same channel see the same frame.

Front Panel and Remote

The front panel is a TM1637 4-digit 7-segment display showing the channel number, a power LED that breathes slowly while the station is idle, and an amber activity LED that flashes during imports. IR comes in through a VS1838B receiver.
The interface target was that normal use never involves a keyboard - you tune, you watch, and the kiosk mode is there when you actually want to manage the collection. Color palette is dark, amber, and gunmetal, which is what the analog broadcast gear it is imitating actually looked like.

Channel 99

Channel 99 is a hidden game console rather than a channel. Two original games are in progress for it, sharing one setting and one continuity rather than being unrelated one-offs.
This is the part of the project furthest from finished, and it is deliberately last - the station has to work as a station before the easter egg matters.

Where the Software Stands

360 files and 320 passing tests across 17 closed phases.
Shipped alongside the playback system: a cloud tier with Stripe integration, an OTA update mechanism, 48 setup wizards, 30 CLI commands, and an SD card image build pipeline. Non-code deliverables done to the same phase discipline - a Kickstarter plan, a manufacturing plan, a QC checklist, a legal pack, and a launch-day playbook.
The image builds and the tests pass. What is not finished is the hardware.

Phase 18 - The Power Controller

A Pi does not have a power button, and pulling the plug on a running filesystem eventually costs you the SD card. Phase 18 is the circuit that fixes that.
An ATtiny85 in an 8-pin DIP sits between the wall supply and the Pi and holds the gate of a P-channel MOSFET, so the microcontroller physically controls whether the Pi has power at all. It runs a four-state machine - OFF, STARTING, RUNNING, SHUTTING DOWN - in 8KB of flash. A button press or an IR command wakes it. Once running, it watches a heartbeat GPIO line from the Pi; when the Pi begins an orderly shutdown the heartbeat stops, the ATtiny waits out the halt, and only then opens the MOSFET.
Supporting parts: an LP2950 LDO for the always-on rail, a VS1838B IR receiver, a TM1637 display, two 3mm LEDs, a 2N2222 driving the panel, and a 1N4007 flyback diode. Currently on the breadboard.

What Is Left

Phase 18 closes when the measured rails match the schematic, the panel behaves under all four states, and the Pi boots, halts, and boots again on command without touching the plug.
Phase 19 is the first full assembly: the TBX image on an SD card in a real Pi in an enclosure, running as one product rather than as parts on a desk.
